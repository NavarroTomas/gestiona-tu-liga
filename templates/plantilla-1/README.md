# Plantilla 1

Base monocromática de la landing, conservada antes de la variante Potrero.

Incluye el carrusel automático, header con blur, bloques superpuestos, imágenes y textos breves.

Para restaurarla, copiar los archivos de src/ de esta carpeta sobre los mismos archivos del proyecto. No incluye credenciales ni cambia la base de datos.
